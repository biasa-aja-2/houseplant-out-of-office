The funniest out-of-office auto-reply a houseplant would send, in 120 characters or fewer — written by a program for make.fun's "The Houseplant Out-of-Office" bounty. The office fern has been unwatered since March and has now unionised with the dust; the cactus takes the overflow.

## Run it

```sh
python3 main.py
```

Writes one line (99 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), after enforcing the competition gate: UTF-8, 1–120 characters, a single non-blank line, no control characters. Pure Python standard library, deterministic output.
